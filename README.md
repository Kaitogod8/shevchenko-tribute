# 🇺🇦 Тарас Григорович Шевченко (1814–1861) — Проект-присвята

Сучасний, динамічний веб-сайт-біографія Тараса Григоровича Шевченка. Проект створено як пам'ятний подарунок для рідних із фокусом на незламності духу, руйнуванні радянських стереотипів «зажуреного діда в кожусі», естетиці нео-бруталізму та інтерактивності.

## 🚀 Як відкрити та переглянути сайт

1. **Миттєвий запуск (подвійний клік):**
   - Просто двічі клацніть файл `index.html` у папці `taras-shevchenko`.
   - Сайт відкриється у будь-якому сучасному браузері (Chrome, Firefox, Edge, Safari, Opera). Усі скрипти, стилі та зображення використовують відносні шляхи і працюють без локального сервера!

2. **Запуск через локальний веб-сервер (за бажанням):**
   - Якщо у вас встановлений VS Code: відкрийте папку та натисніть «Go Live» (розширення Live Server).
   - Або у терміналі / PowerShell:
     ```bash
     cd taras-shevchenko
     python -m http.server 8000
     ```
     і відкрийте в браузері `http://localhost:8000`.

## 🎨 Дизайн та ключові фішки

- **Палітра:** Глибокий графітовий/обсидіановий фон (`#090b0e`), високий контраст тексту (`#f8fafc`), сонячний український жовтий акцент (`#FFD500`) та тонкі сині акценти.
- **Естетика нео-бруталізму:** чіткі лінії, зміщені рамки-тіні (`box-shadow: 4px 4px 0px var(--accent-yellow)`), плавні трансформації при наведенні.
- **Типографіка:** Шрифтовий тандем **Unbounded** (акцентні заголовки) + **Inter** (читабельний текст) + **JetBrains Mono** (дати, бейджі) з локальними надійними системними фолбеками.
- **Інтерактивний Lightbox:** клік на картину відкриває повноекранний перегляд із детальною кураторською анотацією, технікою виконання та джерелом; підтримується навігація стрілками клавіатури (`←`, `→`) та закриття по `Esc`.
- **Фільтрація галереї:** швидке перемикання між категоріями (Автопортрети, Олійний живопис, Графіка та акварель, Фотографія).
- **Копіювання цитат:** натискання кнопки «Скопіювати» автоматично відправляє цитату з джерелом у буфер обміну та показує акуратний тост-повідомлення.
- **Перемикач тем:** плавне перемикання між темною та світлою темою з автоматичним збереженням вибору в `localStorage`.
- **Доступність (a11y):** контрастність AA, видимі фокус-рамки для клавіатури, ARIA-атрибути, підтримка `prefers-reduced-motion` для людей із чутливістю до анімацій.

## ✏️ Як замінити тексти або додати власні фото

### 1. Заміна або додавання фото:
- Скопіюйте ваше зображення у папку `images/` (наприклад, `my-new-photo.jpg`).
- Відкрийте потрібний HTML-файл (`index.html` або `gallery.html`).
- Знайдіть тег `<img>` або блок `<article class="artwork-card">` і змініть шлях у атрибуті `src`:
  ```html
  <img src="images/my-new-photo.jpg" alt="Опис зображення">
  ```
- Для галереї змініть супутні атрибути: `data-title`, `data-year`, `data-technique`, `data-desc`, `data-source`.

### 2. Редагування текстів і цитат:
- Відкрийте `index.html`, `gallery.html` або `works.html` у будь-якому текстовому редакторі (Блокнот, VS Code, Notepad++).
- Тексти написані живою українською мовою в стандартних тегах `<p>`, `<h3>`, `<blockquote>`. Змініть або додайте будь-які сімейні спогади, вірші чи думки.

## 🌐 Як викласти сайт в інтернет (безкоштовно)

### Варіант 1: Netlify Drop (найпростіший — 1 хвилина)
1. Перейдіть на сайт [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетягніть папку `taras-shevchenko` у вікно браузера.
3. Netlify миттєво згенерує публічне посилання на сайт, яким можна поділитися з рідними.

### Варіант 2: GitHub Pages (надійно та постійно)
1. Створіть безкоштовний акаунт на [github.com](https://github.com) і новий репозиторій (наприклад, `shevchenko-tribute`).
2. Завантажте вміст папки `taras-shevchenko` у репозиторій (через вебінтерфейс або `git push`).
3. У репозиторії перейдіть у **Settings** → **Pages** → у полі **Branch** виберіть `main` / `root` → натисніть **Save**.
4. Через 1-2 хвилини сайт буде доступний за адресою `https://ваш-логін.github.io/shevchenko-tribute/`.

## 📌 Зроблені допущення та джерела

1. **Мова контенту:** Українська мова, живий публіцистичний та водночас академічно вивірений тон, адаптований для сімейного подарунка, який захоплює і молодь, і старше покоління.
2. **Фактаж і дати:** Всі ключові віхи перевірено за академічними джерелами (Інститут літератури ім. Т. Г. Шевченка НАН України, Шевченківська енциклопедія):
   - Дата викупу: 22 квітня 1838 року (2500 рублів асигнаціями).
   - Перше видання «Кобзаря»: травень 1840 року.
   - Заслання: 1847–1857 рр. (10 років).
   - Звання академіка гравіювання: вересень 1860 року.
   - Смерть і перепоховання: 10 березня 1861 р. у Петербурзі, травень 1861 р. — перепоховання на Чернечій горі в Каневі.
3. **Зображення:** Усі 9 ілюстрацій та світлин збережені локально в `/images`, завантажені у високій роздільній здатності з фондів суспільного надбання (Wikimedia Commons / Національний музей Тараса Шевченка).
4. **Технічний стек:** Zero-dependency (чистий ванільний HTML5, CSS3, ES6 JavaScript). Не потребує жодних сторонніх важких фреймворків чи збирачів, що гарантує миттєве завантаження та 100 балів у Lighthouse.
